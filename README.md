# 剪贴板翻译器

复制英文，屏幕上自动弹出中文译文。常驻在屏幕右下角的一个小悬浮窗。

**不用装任何东西** —— 只用 Python 自带的功能，不需要 `pip install`。

---

## 快速开始

1. 确认电脑装了 Python（命令行里输入 `python --version` 能看到版本号即可）
2. **双击 `启动.bat`**
3. 屏幕右下角出现一个小窗口，显示「● 监听中」
4. 在任何地方选中一段英文，按 `Ctrl+C` 复制 —— 译文立刻出现

想关掉：点窗口右上角的 `✕`。

---

## 窗口上的按钮

| 按钮 | 作用 |
|---|---|
| **暂停 / 继续** | 暂停后复制任何东西都不会被翻译。**复制密码、密钥前请先点暂停。** |
| **复制译文** | 把当前的译文复制到剪贴板，方便粘贴到别处 |
| **✕** | 关闭程序 |

按住窗口顶部那一条可以拖动位置。

## 你必须知道的几件事

**1. 隐私**
剪贴板里复制的内容会被发送到 MyMemory 的服务器去翻译。
所以**复制密码、银行卡号、私钥之前，请先点「暂停」**。
程序内置了过滤（纯中文不翻、太短不翻、超过 1500 字不翻），但没法可靠地识别出「这是密码」。

**2. 用的是免费接口(MyMemory)**
走的是 MyMemory 这个公共翻译接口，**不需要注册、不花钱、不用密钥**。
但它不是官方服务，有两点要接受：
- 质量比 Google 翻译、百度翻译**差一档**，长句偶尔生硬
- 匿名用户每天有免费额度(个人日常用够)，用完了要等第二天自动恢复

**3. 目前只能英译中**
复制中文不会翻译(跳过)，复制日文、法文等会翻得不准。

**4. 只能翻文字**
图片、PDF 扫描件、视频字幕里的英文翻不了。

**5. 需要联网**
断网时会显示「翻译失败」。

## 常见问题

**双击没反应？**
程序启动失败时会把错误写到同目录下的 `error.log`。
另外可以先在命令行里手动运行 `python translator.py`，这样报错会直接显示在屏幕上。

**提示找不到 pythonw？**
说明 Python 没装好。去 https://www.python.org/downloads/ 下载安装，
安装第一步记得勾选 **Add Python to PATH**（把 Python 加进环境变量）。

**复制了但没翻译？**
按顺序检查：
1. 窗口上是不是显示「已暂停」→ 点一下「继续」
2. 复制的内容是不是本来就是中文 → 中文不会被翻译
3. 内容是不是太短（少于 3 个字符）或太长（超过 1500 字）
4. 窗口里是不是提示「额度用完了」→ 匿名用户每天有上限，第二天自动恢复

## 想自己改点东西？

打开 `translator.py`，最上面有一段「可调参数」：

| 参数 | 默认值 | 意思 |
|---|---|---|
| `POLL_MS` | 400 | 多久检查一次剪贴板（毫秒），改小反应更快但更费 CPU |
| `MIN_LEN` | 3 | 短于这个长度不翻译 |
| `MAX_LEN` | 1500 | 长于这个长度不翻译 |
| `WIN_W` / `WIN_H` | 420 / 280 | 窗口大小 |
| `BG` / `FG` | `#1e1e1e` / `#f0f0f0` | 背景色 / 文字颜色 |
